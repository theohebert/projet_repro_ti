# Reproductibilité

Pour ce qui est de la reproductiilité des experiences réalisées par les differentes équipes, nous nous sommes interessés au travail de 4 équipes et avons reproduit les experiences de 3 d'entre elles. Nous n'avons pas réussi à reproduire l'experience de la team 3 car celle ci a été codée en stan et nous n'avons pas les moyens d'executer simplement du stan.

Pour ce qui est des autres équipes, les experiences ont été réalisées en R ou en python ce qui nous a permis de reproduire leurs experiences avec plus ou moins de précisons (variations de certaines version et de certains paramètre sous différentes contraintes).

## Resultats

Les résultats de nos reproductions se trouvent dans les fichier correspondant au numéro des équipes de l'experience initiale. Pour chaque équipe un ReadMe détail le travail qui a été réalisé et les conclusions que nous avons apporté ainsi que les difficultés que nous avons rencontré. Il faut donc se référer à ces différents ReadMe pour voir nos conclusions.
